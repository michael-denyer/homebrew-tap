# michael-denyer/tap

Homebrew formulae for michael-denyer projects.

```shell
brew install michael-denyer/tap/open-pstack
open-pstack
```

`open-pstack` installs [pstack](https://github.com/michael-denyer/pstack-claude) into the agent harnesses it finds on your `PATH`. The formula builds from the latest pstack-claude release tag; a scheduled workflow moves it to each new release.
